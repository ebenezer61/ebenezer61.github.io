    資料來源

    • 指數、期貨、商品、匯率、VIX、比特幣：Yahoo Finance chart API 的日收盤。期貨是近月連續合約，換月時會有跳動。台指期不在 Yahoo 上，台指期三大法人未平倉在大戶流向頁。
    • 美債殖利率：U.S. Treasury 每日 par yield curve。
    • Fed 利率：New York Fed 的 EFFR 與 FOMC 目標區間（每日）。
    • CPI、核心 CPI、失業率、非農：BLS public API v2（不需金鑰的版本）。
    • 央行決議：依各央行官網新聞稿人工整理，存在 tools/macro/events/cb_decisions.json，每列附官方連結。新的決議出來後要手動加一列。
    • 接下來：央行會議與 BLS 公布日期人工整理（calendar.json）；BEA 的 GDP、PCE 日期每次從 bea.gov 讀取。
    • 新聞：Fed、ECB、BoJ、BoE 官方 RSS，加上 Google News RSS 對固定主題的搜尋；只存標題、來源、時間與連結。

    僅供資訊參考，不是投資建議。程式在 tools/macro，資料在 markets.json、events.json。
