# Figure generators

The inline SVG charts on `/interpretability/` and `/interpretability/traps/`
are generated by these scripts, then pasted into the hand-written HTML.
Each writes a `*.svgfrag` file whose first line is `WIDTH HEIGHT` (for the
`viewBox`) and whose remainder is the SVG fragment, indented to sit inside
the page's `<svg>` element.

| script | figure | data source |
|---|---|---|
| `fig1.py` | orthogonal pathways, 10 paired bars | `pathway_totals.txt` values, hard-coded after verification |
| `fig2.py` | dose-response, two panels | `intervention_results.txt` values |
| `fig3.py` | 18-name generalisation dot plot | `gen.json`, extracted from `probe_name_generalization.txt` |
| `trapfig.py` | binding traps, paired bars by pair | `probe_binding_traps_gemma-2-2b.txt` values |

`gen.json` is committed alongside; the other scripts carry their numbers
inline; every value was recomputed from the circuit-tracer repo's committed
graph JSONs / probe outputs before being hard-coded here.

Run each script in this directory; it writes its `*.svgfrag` beside itself.
Colors are CSS custom properties (`var(--viz-*)`)
resolved by the pages' own light/dark palettes, validated for color-vision
separation and contrast against both surfaces.
